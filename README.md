# Minds Garden 1.6.1

Extract the entire folder. Double-click Minds_Garden_v1.6.1_Open.html or START_MINDS_WINDOWS.bat to explore on Windows. Keep the public folder beside the HTML file for the cover and icons.

For a phone or public link, serve the contents of dist from a static HTTPS website. Open its URL in your phone browser and choose Add to Home Screen. The manifest supplies Android icons, and the Apple touch icon is 180 × 180. The favicon is 32 × 32. The Open Graph cover is 1200 × 630. If your hosting platform requires an absolute sharing URL, set og:image to the deployed URL of brand/cover-1200x630.jpg.

For development, install the dependencies with npm install, then use npm run dev. Use npm run build to regenerate dist and the double-click edition.

## Explore

The site opens directly into the garden. Use About to reopen the cover. In Philosophy, select the framed daily thought or the pen on the desk. Plant this thought saves the writing and grows a flower. Enter the glasshouse from the garden building or navigation. Select a bloom to read its original text and date. More than nine flowers are arranged on additional shelves. Earlier compatible reflections in the same browser storage also appear as flowers.

In Music, select the piano to play or record. Select the score stand for the music library. In Food, choose a dish to open its cultural story and kitchen notes. Use the card action to see it on the pavilion table.

Reflections, diary pages and compositions are stored in the current browser and site origin. Use the available export buttons for a backup.

## Upload images

The upload-images folder contains the five ready-to-upload assets. The cover, desktop screenshot, mobile screenshot, app icon and favicon are all below 5 MB. The desktop capture is 1280 × 720, and the portrait capture is 390 × 844. The larger cover master is in public/brand. The cover was generated with the built-in image generator from a brief for a botanical garden featuring a flowering kapok, greenhouse, clock tower, pond, tea pavilion, cottages and pinwheel.
